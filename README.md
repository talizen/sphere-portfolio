# Sphere — Spherical Work Gallery

Hundreds of work cards form a 3D sphere you can drag and spin, then morph into a heart, smiley, star or grid. Click any card for the full piece; all works live in one content file. Made for photographers, illustrators and designers.

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build & deploy

```bash
npm run build
```

The static site is written to `dist/`. Upload it to any static host — Vercel, Netlify, Cloudflare Pages, GitHub Pages, S3 or your own server.
